# Marketing

Скрипты для постов в соцсети: примеры печати из реальных сессий и коллажи из них.
Всё запускается из корня проекта через `venv/bin/python`.

Результаты (`samples/`, `collages/`, `frames/`, `sessions/`) в git не хранятся —
пересоздаются командами ниже.

## Папки

```
marketing/
  sessions/   ← скачанные с Яндекс.Диска архивы сессий (.zip)
  samples/    ← отпечатки, собранные из сессий
  frames/     ← кадры, нарезанные из видео
  collages/   ← готовые картинки для постов
```

## 1. Примеры печати из сессии

`generate_samples.py` собирает все форматы тем же `backend/composer.py`, которым
печатает будка, — примеры пиксель-в-пиксель совпадают с реальным отпечатком.

```bash
venv/bin/python marketing/generate_samples.py \
    marketing/sessions/2026-08-01_09-51-31_2450f1b2657f6bc3ceed7.zip \
    --pack kvas01aug26
```

Без `--pack` берётся активный пак из `config_app.json`. Принимает и распакованную
папку сессии.

Результат — `samples/<сессия>/<pack>/` с тремя видами одного и того же:

| Папка | Что это | Когда нужно |
| --- | --- | --- |
| `print/` | `3688×2480`, ровно то, что уходит в DNP | проверить геометрию печати |
| `paper/` | обрезано по `print_trim` — что гость держит в руках; strips уже разрезаны на две полоски | коллажи |
| `web/` | `paper/`, уменьшенный до 2048 по длинной стороне | вложить в пост как есть |

Плюс `samples/<сессия>/source/` — оригиналы фото и видео сессии, скопированные из
архива без пережатия.



## 2. Коллаж трёх форматов

`build_formats_collage.py` показывает, что гость может выбрать: открытка, одно
фото, две полоски веером. Тёмный фон, подписи шрифтом будки, реальные пропорции —
полоска ровно такой длины, как ширина открытки, потому что это один лист 4×6.

```bash
venv/bin/python marketing/build_formats_collage.py \
    --session 2026-08-08_16-06-26_b9e1d30665888c9ed50d7 \
    --pack park08082026 --single 3 --variant frame
```

За один запуск делает три раскладки — выбрать нужную:

- `formats_<pack>_mosaic.jpg` — открытка над одним фото, полоски рядом;
- `formats_<pack>_row.jpg` — три формата в ряд (широкий, хорош под текст);
- `formats_<pack>_column.jpg` — в столбик (узкий, под вертикальный пост).

`--single 1..4` — какой кадр показать как «одно фото», `--variant frame|plain` — с
рамкой шаблона или на весь лист. Дефолты — константы вверху скрипта, там же углы
наклона, перекрытие полосок, цвет фона и текст подписей.

## 3. Кадры из видео

Скриншот даёт пожатый кадр в разрешении экрана; так забираются исходные пиксели.

```bash
mkdir -p marketing/frames/IMG_7640
ffmpeg -v error -y -i ~/Desktop/IMG_7640.MOV \
    -qscale:v 2 -qmin 1 -qmax 1 -vsync 0 \
    marketing/frames/IMG_7640/frame_%04d.jpg
```

Нумерация по порядку, 30 кадров в секунду: момент на 5-й секунде — примерно
`frame_0150`.
