# Рекламная карточка Яндекс.Диска

`photobooth_card.jpg` автоматически загружается как
`000_фотобудка_контакты.jpg` в корень каждого нового event и копируется в
каждую новую публичную session-папку.

Файл можно заменить без изменения кода. Требования: обычный JPEG, размер до
5 МБ; для просмотра с телефона рекомендуется горизонтальный макет 3:2 не меньше
1800×1200. После замены новый MD5 будет замечен автоматически. Уже завершённые
session-папки задним числом не обходятся, новый вариант получат последующие
сессии.

При старте приложения фоновый сервис Яндекс.Диска проверяет карточку в корне
текущего `yadisk_folder` из `config_app.json` и загружает её только при
отсутствии или другом MD5. При создании session сначала публикуется папка и
становится доступен QR, после чего карточка копируется в неё серверной операцией
Яндекс.Диска. Локальный JPEG повторно для каждой сессии не загружается.
